# Phase 1：Cube-Sphere 火星网格沙盘

## 背景与目标

- 对应会话-1 开始的《最后的 AI》原型开发任务。
- 初始目录为空且无 Git 仓库；首轮先明确整体架构，再实现并验证 Phase 1。
- 证明六个面是同一个闭合拓扑，并用可交互 3D 场景检查跨面坐标与路径。

## 约束与决策

- 规则与 Three.js / React 分离，所有连接集中从面基向量推导。
- N=8、384 格。使用无权 BFS，拓扑距离不受渲染曲率和高程影响。
- 本阶段不实现单位、战斗、WEGO、AI；设施和路径探针只用于地形/拓扑展示。
- 采用程序化几何与本地字体，无运行时外部素材依赖。

## 代码变更

- `src/game/grid/`：基向量、跨面变换、距离、路径、范围、投影与测试。
- `src/data/`：固定火星地形和三个战略节点。
- `src/rendering/`：程序化地形、设施、镜头、路径动画与拾取。
- `src/ui/`：阶段一战区界面、路径规划、六面导航与帮助。
- 项目运行配置、README、AGENTS、CLAUDE 与文档索引。

## 关键风险

- 边缘坐标反转和朝向转换；通过所有有向边遍历验证。
- 镜头在极点翻转；自动镜头避免奇点，用户输入可取消。
- Three.js 资源泄漏；卸载时释放几何、材质、事件与动画循环。
- 手工地形可能割裂可行路线；固定路径场景必须可达。
