# 蜂窝球面替换四边形网格

## 背景与目标

- 对应会话-10 开始的调整：用户期望星球表面为六边形，并指出原立方体投影使四边形变形。
- 当前分支仍为 `main`，与上一轮相同；项目尚无 Git 提交，原文件仍为未跟踪状态。
- 替换网格的真实几何和规则，保留闭合行星探索、寻路和预演。

## 约束与决策

- 原六面 NxN 方格拓扑被用户的新需求取代，改用二十面体细分对偶。
- 默认细分频率为 6，总计 362 格：350 个六边形、12 个五边形、1080 条无向边。
- 球面不能由平面正六边形无变形铺满；保留五边形，禁止虚构第六个邻居或用隐藏传送绕过闭合约束。
- 六个方位分区用于镜头、着色和任务命名，不再承担坐标或邻接规则。
- 规则内核继续保持纯 TypeScript，不依赖 React、Three.js 或外部网格库。

## 关键实现

1. 三角面按频率细分，共享顶点去重后映射到单位球面。
2. 使用球面 Voronoi 单元进行 24 次 Lloyd 松弛，把格心推向面积重心。
3. 最终多边形使用三角形归一化重心作为共享角点，同时改善面积与边长均匀性。最终形状不是严格 Voronoi 图。
4. 默认六边形面积相对标准差约 2.70%，最大／最小面积比约 1.090，单格最长／最短边比最大约 1.162。并非完全相等的平面正六边形。
5. 格子保存逆时针顶点和按边排列的邻居 ID；`convertAcrossEdge` 返回目标格、反向边索引与球面切向朝向。
6. 多边形渲染采用细分三角扇、真实边框和地形裙边，拾取直接命中对应的五／六边形。

- 类型：自动规则测试；优先级：高。

- 验证 362 格全连通、1080 条边、720 个共享顶点，满足欧拉公式。

## 风险与未验证项

- 旧 `{face,x,y}` 数据不兼容新 ID；目前没有存档系统。后续存档必须携带网格版本，改变频率或算法需要显式迁移。
- 球面曲率、五边形附近的形状差异和屏幕透视仍会造成少量不规则感，不能承诺所有格子完全等边等角。
- Safari / Firefox、实体触屏设备和长期 GPU 资源稳定性未专项验证。
- 战斗、WEGO、AI 仍属于后续阶段，本次只调整 Phase 1 网格系统。
